# 太阳系模型来源与许可

- 素材名称：Solar system [REAL SCALE] 2k textures
- 作者：FyorDev
- 来源：https://sketchfab.com/3d-models/solar-system-real-scale-2k-textures-febde2b6e3f64b06965620fd3ddc97c2
- 许可：CC BY 4.0
- 本地原始文件：`solar_system_real_scale_2k_textures.glb`

项目仅将该 GLB 用作太阳、行星、月球、小天体和土星环的网格及纹理来源。模型内所有天体原本重叠在原点，没有轨道动画；运行时轨道位置由 NASA/JPL 轨道根数计算。
