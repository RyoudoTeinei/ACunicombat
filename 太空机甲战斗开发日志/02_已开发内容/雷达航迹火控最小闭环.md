# 雷达航迹火控最小闭环

## 完成范围

已经建立第一阶段可玩的雷达闭环：

`SimWorld 真值 -> RadarSensorSystem 匿名量测 -> RadarTrackManager 航迹 -> TrackSnapshot -> FireSolutionSolver -> 武器、导弹与 HUD`

火控、瞄准、开火许可和导弹中段制导只读取 `TrackSnapshot`，不直接读取目标 `Transform`。场景目标的 `Transform` 只用于把物理真值写入仿真世界，以及命中后的碰撞和伤害结算。

## 雷达检测

- 支持雷达与目标参数注册，包括波束、驻留周期、最大距离、频段、波形、功率、分辨率和雷达散射截面积。
- 按驻留调度和波束方向产生检测，不是全向、全时、必然发现目标。
- 量测包含距离、方向、径向速度、信噪比和干扰比，并加入与测量质量相关的噪声。
- 近距离且无法按距离、角度或速度分辨的回波会合并。
- 主动雷达工作时会生成发射记录，为后续被动告警和电子战保留接口。

## 航迹管理

- 使用 CMKF 完成预测和位置量测更新，并维护状态协方差。
- 当前使用最近邻关联；连续 5 次扫描中的 3 次命中后确认航迹。
- 量测短时中断时进入外推，超过生命周期阈值后降级或删除。
- 当前容量为 32 条航迹，对外只发布 `TrackSnapshot`。

## 火控与武器

- 使用航迹的位置、速度、时间戳和协方差计算匀速拦截解。
- 开火许可同时检查航迹状态、数据新鲜度、解算是否成立和解算质量。
- 枪炮在没有有效航迹或开火解时不会把目标真值当作备用瞄准数据。
- 导弹保存 `TrackId`，飞行中按最新航迹更新目标点；量测暂时丢失时使用航迹外推结果。
- 测试场景中的目标继续负责命中判定、生命值和伤害反馈。

## 尚未完成

当前成果是最小闭环，不代表完整雷达系统已经完成。后续仍需实现多种扫描模式、多目标优先级调度、地形遮挡和杂波环境、完整电子战与欺骗、数据链与敌我识别、制导通道资源竞争，以及正式的雷达战术界面和目标选择操作。
