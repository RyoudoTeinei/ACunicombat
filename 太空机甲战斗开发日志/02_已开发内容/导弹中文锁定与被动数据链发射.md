2026-10-22。将目标标签、导弹发射条件与被动/数据链制导接入同一装备执行流程；没有增加新的内装槽位。

红色目标框、距离和文字仅表示玩家用准星指定的目标。满足导弹发射条件才附加“·锁定”，与是否指定、是否红框独立：未指定但可发射的目标仍可显示“数据链·锁定”等标签；指定但不可发射的目标为红框而没有后缀。已识别友军仍保持地图的友方蓝色，不由攻击准星指定。指定不会改变敌我身份。

准星移到另一机体可以切换指定并解除旧 STT；移到空白时保留当前指定，直到换目标、主动解除或联系人失效。飞机目标附近出现的新导弹不会抢走指定。选择不受本机雷达扫描锥限制，但实际跟踪和发射仍受各自的物理条件限制。

本机雷达关闭不会继续显示“搜索/跟踪”。数据链证据变旧时保留其模式名称，但撤销锁定资格；没有可用三维来源时可以显示被动状态，但不会制造可发射解算。这里“搜索不直接授权导弹发射”是本项目当前玩法规则，不作为所有现实雷达工作方式的定义。

## 数据链工作原理

- `MechCooperativeTelemetry` 通过现有物理链路发送新的 `LinkMessageKind.TargetObservation`，载荷仅来自发送方自己的传感器航迹，不从收到的目标报告再次转发制造反馈循环。
- 目标位置、速度、协方差和观测时间保留；接收时间不能替代原始观测时间，也不能凭“收到数据链”提高测量精度。
- `MechSharedTargetTracks` 按观察者分组，一组内基于共同输入做一对一分配；同一观察者已经分辨的不同目标不会互相吞并。不同观察者可以支持同一个本机联系人。
- 报告受到现有带宽、传播和处理延迟、终端及发射策略限制。过期、未来时间、重复时间和非法协方差报文不会作为新观测。
- 本机使用自己的导航位置/速度识别可能被友机回报的本机回波，避免把本机当成新的可攻击目标；这不读取敌机真实身份。
- 本机关闭雷达后，仍可使用足够新且质量合格的目标报告，经本机火控解算后发射，并通过自身数据链给导弹提供中段更新。它仍需要可用的数据链和火控资源。

## 被动发射与制导原理

弹药能力字段为 `MechWeaponPerformance.supportsPassiveRfHoming`。现有 MTR-4340 左/右配置及其生成工厂已启用；没有该能力的弹药不能因看到了辐射就获得被动发射资格。

发射前用本机接收的雷达波形、测向和新鲜程度，与当前可知平台航迹进行关联。同波形因测向噪声形成的多条告警记录不是多个独立目标，但平台关联仍须唯一；不同候选发生歧义时不能直接认领。

重要边界：当前被动发射仍需要最近的独立三维位置/速度估计，例如本机此前的测距或友机报告。只有被动方位、没有可靠距离时，拒绝精确发射；本次没有伪造距离，也未宣称实现完整的纯方位机动目标定位。

发射后导弹通过独立被动接收器侦收实际执行的雷达辐射。场景真实几何只进入传感器传播边界，制导得到的是带噪方位、频段和波形，不是敌机 Transform 或真实目标 ID。导弹结合已有运动估计修正航向，不能把方位更新冒充新的距离测量，也不能据此直接更新近炸距离证据。

进入自身可靠主动获取范围，或辐射丢失超过保持时间后，导弹允许打开自己的主动雷达搜索。本机雷达不会随之开启。纯被动发射不占用本机导弹上行订阅；导弹自己的报告与通信策略仍走原有链路规则。

中段报文的序列号更新不代表目标观测更新。重复搬运同一份旧航迹不能续满导弹记忆；记忆期限依据载荷的观测时间计算。

## 发射检查与 API

- HUD/外接 UI 使用 `MechTestWeaponSystem.CanReleaseMissileAt(TrackId, out MechTargetTrackingMode)`。该查询复用装备执行器检查，不排队、不预留通道，也不建立 STT。
- `MechRadarController.PreviewMissileRelease` 是传感器来源与火控解算层检查，不能代替最终装备就绪判断；不要仅据其返回值显示“·锁定”；红框只读取 CandidateTrackId。
- 动作提交仍使用 `CommandFireSlot` / 共同仲裁器。发射时重新检查身份、当前装备实例、弹药、冷却、展开、能量、制导资源与当前观测，避免 HUD 旧状态直接授权。
- 发射位置安全范围包含位置不确定性；预计拦截点不得超出该弹药的最大飞行距离。当前距离较远、但目标正在接近并形成可达拦截点的情况不会简单按初始距离拒绝。
- 发射资源声明由实际来源决定：集中跟踪使用雷达/数据链支撑，数据链发射不强制开启本机雷达，被动发射不假报本机雷达或上行需求。
- 当前装备的编队确认/自由攻击规则和 IFF 交战许可继续生效，没有绕过它们建立第二套发射器。

底层综合回归 `Artifacts/PassiveRelease-20261022/final/results.xml` 为329/329；指定、真实发射与镜头回归 `designation-final/results.xml` 为26/26；四种颜色/就绪组合和可玩场景回归 `designation-verified/results.xml` 为15/15。目录均位于 `Artifacts/PassiveRelease-20261022`。最终扫描范围边界复核见 `designation-boundary/results.xml`。此前的编译、诊断和失败结果原样保留。

覆盖规则与真实链路：

- 搜索观测本身不授权，数据链过期/未来时间拒绝，非反辐射弹药不能被动发射。
- 友机真实雷达、正常调度和物理链路把敌方航迹传给关雷达的接收机。
- 数据链模式下实际发射弹体，并收到更新后的中段观测；本机不建立 STT、不打开雷达。
- 本机雷达与上行都关闭时实际被动发射；弹体自己的接收器继续得到实际辐射，目标停机后转主动搜索。
- UI 多次查询不占用通道；本机回波排除、同源多目标不合并、最大距离及近距不确定性安全检查。
- 正式可玩场景运行 12 秒，正常 AI/传感器/无线链路，6 秒后关闭本机雷达，检查中文标签并保存截图。这不是 120 秒完整实战连续性验收。

可选传输诊断：`MechCooperativeTelemetry.TraceTargetSharing=true`，通过 `TargetShareDiagnostics` 查看最近的发送/接收状态、观测时间及本机回波排除情况。默认关闭，避免每帧大量日志。
