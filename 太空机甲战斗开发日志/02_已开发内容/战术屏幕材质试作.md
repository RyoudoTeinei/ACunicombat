# 战术屏幕材质试作

2026-10-16。先验证屏幕表面质感，尚未替换 M 地图的太阳系内容为战场态势数据。

新增 Resources/Shaders/MechTacticalScreen.shader。采用屏幕空间乘色覆盖，包含固定像素点阵、细扫描线、很轻的 RGB 子像素变化、12 Hz 微弱颗粒及边缘衰减。默认强度 0.65，点阵周期 3 个屏幕像素。没有邻域采样的辉光、景深模糊或几何弯曲，本轮优先保留文字清晰度。

MechSolarSystemMap 在图形及文字绘制后统一覆盖材质；仅在地图显示时绘制。左下“屏幕质感：开/关”支持同场景比较，Inspector 可调整强度和点阵尺寸。使用 unscaledTime，暂停战斗时仍有颗粒变化。没有新增输入拦截或更改地图缩放操作；材质随组件销毁释放。

主项目运行时代码编译通过，仅既有弃用警告。隔离 URP 工程确认 shader 无编译错误并以 GPU 渲染样张成功，已查看导出结果。Artifacts/TacticalScreen-20261016/before.png 和 surface.png 为合成战术符号的材质样张，不是实战地图截图；导出已做线性到显示色彩转换。未在用户正在运行的主项目内手动操作验证。

## 第五版：独立逻辑像素与光学重建

重写 MechTacticalDisplay.shader 为两个 pass。第一阶段按源像素与逻辑单元边界的实际覆盖面积在线性颜色空间累加，生成独立 HDR 逻辑像素纹理；单元中心采样不再作为替代。样张采用 1600×1000 输入、1280×800 逻辑分辨率。面积积分阶段调用方应限制单次缩小倍率以控制开销，当前样张为 1.25 倍。

第二阶段只绑定逻辑像素纹理，没有原始高清画面旁路。每个单元采用有限矩形发光面与高斯点扩散函数，通过解析积分覆盖输出像素的采样面积，邻近单元共同贡献边界光。低黑电平也由各单元发出，不再以独立网格或噪声覆盖背景。缩小时使用逻辑纹理 mip 链并淡出不可分辨的单元结构。光学模型为显示效果近似，不是对参考屏幕硬件的测量拟合。

输出 Artifacts/TacticalScreen-20261016-v5：display.png 完整画面，detail.png 是同一逻辑纹理的局部重新渲染放大（不是放大成品截图），logical-pixels.png 为独立逻辑像素，minified.png 检查缩小效果。TacticalDisplayPreview.cs 保存渲染流程，verification.txt 保存 GPU 验证结果。

GPU shader 编译/渲染通过；实际积分检查验证一个偏离采样中心的白色源像素在 2×2 缩小后贡献 0.25 亮度，总亮度和最大值均正确。已查看整图、局部及缩小图。本轮仍为样张流程，未替换旧 M 地图全部 UI 合成，也未做游戏内帧耗时测量。
