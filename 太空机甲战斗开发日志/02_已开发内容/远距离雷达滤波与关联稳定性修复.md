# 远距离雷达滤波与关联稳定性修复

2026-10-16。针对四机地图出现十四条雷达航迹、负协方差和约 31.49 km/s 异常估速的调查继续修复。只修改 Cmkf、RadarTrackManager 和新增测试；未修改 M 键地图、询问应答及其协议。

## 原因与修复

1. 单精度方向并非双精度下的精确单位向量。原 R = σr² ddᵀ + r²σθ²(I-ddᵀ) 在远距离、横向误差远大于测距误差时可产生负方差。改为双精度归一化、正交基正系数外积构造，初始化加入二阶角度去偏与径向曲率方差。
2. 原逆矩阵使用余子式/行列式且允许负行列式。改为缩放 Cholesky 求解；非正定新息拒绝。位置/速度更新先在候选状态计算，经有限性及全矩阵有效性检查后提交；位置更新失败记录 invalid_filter_update，不增加命中证据。
3. 原关联只按三个坐标轴方差归一化，丢弃强相关项。改为完整协方差 NIS。
4. 单纯改用笛卡尔 NIS 仍会把远距旁瓣的等距离曲面当平面。关联及递推更新使用预测视线坐标下的距离/角度新息，并计入观测和预测角度不确定性产生的二阶曲率误差，防止旁瓣启动阶段通过不断旋转的测距雅可比制造虚假的角度精度。
5. 同一时间戳先处理精度高的回波，避免低精度回波抢先建轨；初始化保存完整协方差，不再用同一份位置测量更新第二次。
6. 多普勒投影计入视线角度误差及当前速度不确定性，避免低精度旁瓣方向被当成精确速度约束。

未加生产速度硬上限、未合并显示图标、未按场景真值数量裁剪航迹，也未扩大通用 5σ 门槛来让测试通过。

## 回归

- 原负方差最小复现现在必须得到合法协方差，连续更新不发散。
- 负方差输入必须拒绝且不能改变健康滤波器。
- 强相关新息沿窄轴的偏离必须被正确识别。
- 四实体生产传感器/跟踪器回归：初始约 40–100 km，四组种子 1/7/42/1234，各运行 40 秒，主瓣/旁瓣交替。使用真实生成的有噪声量测，不注入航迹或关联结果。
- Unity Play Mode：四个移动 CombatTestTarget，通过正式 MechRadarController、SimulationDriver 与雷达传感器运行 30 秒。受控指向命令让每台目标交替进入主瓣/旁瓣，自动搜索仍工作。没有加载地图或询问应答组件，也不是手动视觉验收。
- 场景 RCS 100㎡，使旁瓣回波充分可见，以覆盖本次高动态范围问题。所有断言只针对这些明确场景，不承诺任意干扰/运动/信噪比下绝不出现暂态假航迹。

全程检查最多四条并发航迹、总共只出现四个 TrackId、速度有限、协方差对角非负。四组仿真末态每台位置误差 <100 m、速度误差 <50 m/s。实测最高速度分别约 129.96、132.53、129.67、129.71 m/s；Unity 实景最高约 100.29 m/s，均无异常高速。

综合自动回归 139/139；最终加强的专项 8/8。主项目当前运行时代码编译通过，仅已有 API 弃用警告。综合测试执行在隔离 URP 工程，未宣称主项目全量批处理通过；此前 APS 间歇用例本轮通过，但本轮没有专门修复或证明其所有时序下永久稳定。
