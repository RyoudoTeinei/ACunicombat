# 角色动作导入验证

## 已完成

- 检查了多个 AC6 角色 FBX，确认它们包含骨架但不包含 Action。
- 确认 `chr/AC - c0000` 的 `.hkx` 是 Havok 2019 动画容器，不能直接交给 Unity 或 Blender 当普通动画读取。
- 生成了一个基于 `ALLMIND - c4201` 骨架的测试动作 FBX，用于验证 Unity 的骨架动画导入链路。
- 增加了 Unity 编辑器菜单 `Tools > ACunicombat > Animation > Import AC6 Rigged Test Animation`，用于创建测试 Animator Controller 和预览 prefab。
- 增加了 `MechProceduralPoseAnimator`，用于让当前换装系统拼出的机体按槽位做程序化姿态动画。
- 增加了 Unity 编辑器菜单 `Tools > ACunicombat > Animation > Add Procedural Pose Animator To Selected Mech`，选中 `Sample_PlayerMech_Rig` 后可一键添加到当前装配机体。
- 为 baked Melander 和 raw baked weapon 两个测试 Loadout 补充 `AC6_BLEND_BST_Test_Vector` 推进器，避免换装校验报 `REQUIRED_SLOT_EMPTY / Booster`。
- 下载并解压 DSAnimStudio 5.0-RC6.1，确认该版本包含 AC6 支持资源和 `Export Skeleton & Animations...` 工具。
- 阅读 DSAnimStudio 5.0-RC6.1 源码，确认其可导出 Havok XML/HKX，但没有直接 HKX -> FBX/glTF 导出功能；FBX 动画功能主要是导入到 HKX。

## 注意

`AC6_C4201_TestAction_Preview` 是为了测试导入链路而生成的完整骨架预览机，不会驱动当前换装机体。当前换装机体使用 `MechProceduralPoseAnimator` 做槽位级程序动画。真正导入 AC6 原动作还需要 `.hkx/.bhv` 转换。
