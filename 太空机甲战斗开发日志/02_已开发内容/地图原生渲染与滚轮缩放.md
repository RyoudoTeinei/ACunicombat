# 地图原生渲染与滚轮缩放

2026-10-16，修复静态样张与实际游戏显示不一致。

## 修复

- 原流程固定 1600×1000 UI 源、1280×800 逻辑纹理、1600×1000 输出，再拉伸填满窗口，造成第二次插值及比例失真。现在按实际窗口计算整数像素的 16:10 视口，最终纹理尺寸与视口完全相等；宽高比不一致时留边，避免拉扁圆圈。
- UI 源绘制为最终视口的两倍分辨率，CanvasScaler 保持统一 1600×1000 布局坐标，动态字体按高分辨率重新生成。源纹理使用 Point 采样，随后一次面积积分进入逻辑像素，按原生输出分辨率重建与玻璃散射。
- 窗口尺寸变化会重建纹理、更新 UI 缩放器。兼容热重载时旧相机/Canvas 残留而新增字段为空的情况，避免沿用旧流程。
- AC6CombatShowcaseController 的旧动作演示面板在地图打开时停止绘制。

## 滚轮

兼容新 Input System 的归一化滚轮值 1 与旧 Windows 值 120，每格对应同样明显的缩放幅度。向上放大、向下缩小，以光标下的地图位置为锚点；范围 5–2000 km。右侧信息框不响应地图滚轮。Home 恢复 150 km、默认朝向和中心。右键拖动仍可旋转/调整俯仰。

文字和符号保持可读尺寸；缩放改变战场比例与目标间距，不拉伸已合成的像素图片。绘图区域加入裁切，放大后的距离圈和目标不会盖住信息框与页脚。点击坐标按同一视口逆变换，避免留边后错选。

## 按倍率渐变的渲染路径（2026-10-16）

用户调整方向：替代前一节同比例放大发光单元的方案。默认和 Home 均为 1 倍，滚轮范围为 1–5 倍。1 倍从高分辨率源直接面积降采样至原生输出，只保留极弱玻璃散射，不经过发光单元重建。1–3.5 倍平滑混合清晰路径与像素重建路径，3.5–5 倍完全使用像素路径；RGB 子像素强度及散射随倍率独立变化。

像素单元尺寸使用平滑曲线从 1 增至 1.85，图形和字形仍按实际内容倍率放大。因此 5 倍时字形占据更多逻辑像素，避免把固定少量像素越拉越大。所有参数过渡连续。右侧及底部悬浮信息使用清晰路径，保持固定尺寸。
