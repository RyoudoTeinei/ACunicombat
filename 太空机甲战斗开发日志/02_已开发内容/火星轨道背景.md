# 火星轨道背景

## 当前实现

- 战斗基准高度：火星平均半径上方 `400 km`。
- 火星平均半径：`3,389.5 km`。
- 运行时采用缩放空间表现，HUD 高度仍按真实尺度计算。
- 颜色来源：`Mars-Surface-PBC-32k.pak`，按原生立方体布局保留为六张 `8192 x 8192` 表面贴图，赤道总采样密度为 32K。
- 地形来源：`Mars-Bump-PBC-32k.pak` 的六面高程瓦片，生成 `16384 x 8192` 法线图。
- 云层来源：`Mars-Clouds-HD-2k.pak`，分别使用沙尘与水冰两套六面灰度遮罩，并以不同颜色和低速自转叠加到受光表面。
- 初始轨道下点：原始颜色图约东经 `60.5°`、南纬 `13.4°`，位于明暗地貌与陨石坑密集区。

## 2026-08-25 画面修正

此前初始轨道下点位于颜色变化较弱的区域，并且材质把已经带有明暗信息的颜色图再次用线性漫反射压暗，造成大面积均匀红色和细节丢失。

本次调整：

- 将初始轨道下点改到原始颜色图中真实存在的明暗地貌交界区。
- 日照改为保留白昼颜色细节的非零下限，夜面仍由几何法线单独遮蔽。
- 对颜色图加入受控的四邻域锐化，减少近地轨道放大后的软化。
- PAK 法线强度由 `0.38` 调到 `0.58`，加强陨石坑和山脊高差，但不生成虚假的大型地貌。
- 日照强度由 `0.70` 调到 `0.96`，大气边缘混合由 `0.14` 降到 `0.09`，避免颜色层次被统一染红。

Unity 已在 `2560 x 1440` 下重建和截图验证：颜色图与法线图均按 `16384 x 8192` 导入，Shader 和 C# 无编译错误；正下方画面已能区分暗色地貌、亮色高地、陨石坑与局部高差。

## 2026-08-25 太阳光照

- 火星材质不再依赖 URP 自动挑选的主光，而是接收与天空太阳、机体主方向光相同的世界太阳方向。
- 表面亮度按球面法线和局部 PAK 法线的 `N·L` 计算，白昼最低补光由 `42%` 降为 `2.5%`，夜面环境反射降为 `0.15%`。
- 晨昏线单独计算，薄大气边缘只在受光侧出现，夜侧不会形成一圈均匀红光。
- 场景太阳方位调整为约 `53°` 相位角，使轨道战斗视角能看到由受光侧到暗侧的变化；天空太阳、火星照明和机体投影保持同向。
- `400 km` 正下视角只覆盖较小的地表区域，远离晨昏线时该区域受光接近一致是正确结果；明显昼夜分界主要出现在地平线方向或晨昏线轨道段。

## 2026-08-26 Surface 与 Clouds PAK 接入

- 不再把原 GLB 的 8K 颜色图作为主要表面。着色器直接读取 `Mars-Surface-PBC-32k.pak` 解出的六张 `8192 x 8192` 立方体面，保留素材原有的暗色高地、浅色平原、陨石坑和沟槽颜色层次。
- 六面贴图采用立方体方向采样，避免把 32K 数据先转换成经纬图而损失极区分辨率；边缘使用 PAK 瓦片自带的重叠像素和 Clamp 采样。
- 沙尘云与水冰云分别保留为六张 `512 x 512` 灰度面，并由高于地表约 `12 km` 的独立透明云壳渲染；地表只接收同遮罩产生的轻微云影。
- 表面贴图在 Standalone 平台使用 BC7、最高 `8192`、各向异性过滤和 mip streaming；云层遮罩使用线性 BC4。
- 原 GLB 颜色图仍作为缺失 Surface 资源时的回退，不再参与正常渲染。
- 本地生成的大体积贴图位于 `Assets/_Project/LocalGameAssets/Environment/Mars/SpaceEngineLayers`，由 `Tools/ExtractMarsSpaceEngineLayers.py` 从 PAK 重建，不纳入版本库。

Unity 已在 `2560 x 1440` 下完成轨道地平线与正下方两种视角验证：Surface 六面均按 `8192 x 8192` 导入，两套 Clouds 六面均按 `512 x 512` 导入；Shader 和 C# 无编译错误，未发现明显立方体面接缝。

## 2026-08-26 自转与大气边缘

- 火星本体按恒星自转周期 `88,775.244 秒` 绕本地南北轴连续转动，默认时间倍率为 `1`；云壳继承本体自转，同时保留自身较慢的相对漂移。
- 增加独立大气散射壳，不再只在地表球内部绘制 Fresnel 颜色。大气有效高度约 `20 km`，能够在行星外轮廓形成薄光晕。
- 大气亮度按视线穿过球壳的光程近似计算，因此在接近地表切线处最明显，向外缘和行星正面逐渐衰减。
- 大气壳使用与天空太阳、地表和机体相同的太阳方向；受光侧清晰可见，夜侧显著减弱，避免整圈等亮描边。
- 云层采用独立透明材质。测试轨道使用经度相位选择中纬度真实水冰云带，没有再把极冠云层强行倾斜到战斗区域。

Unity 已重新生成 `2560 x 1440` 轨道地平线截图：云层轮廓、地表明暗梯度和受光侧薄大气边缘可同时辨认；最近一次重建后的 Shader 与 C# 编译错误为 `0`。

## 已知限制

当前颜色已经达到 Surface PAK 的原生 32K 密度，但高程仍由 Bump PAK 转换成 `16384 x 8192` 法线图，尚未像颜色层一样直接按六面 8K 采样。若后续需要进一步强化极近轨道的微地形，可把 Bump 也改为六面采样，或加入视差/顶点位移；这不会凭空增加 Surface PAK 中不存在的颜色细节。

六张 8K BC7 表面贴图完整驻留时显存占用较高，因此已启用 mip streaming。后续制作正式关卡时需要设置纹理流送预算，并通过 Profiler 检查目标显卡上的常驻 mip 与峰值显存。
