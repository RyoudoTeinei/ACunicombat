# IFF 固定身份与联合行为判敌

用户明确保留首次确认友军或敌军后的固定身份规则，不启用自动撤销友军身份。地图、问询应答协议及训练开火权限不修改。

## 新增规则

- 明确攻击：保留原有攻击证据乘积分数 >= 0.8 的路径；新增行为质量 >= 0.95、来源关联 >= 0.8 的独立检查。仅适用于已由行为跟踪器确认的 ObservedAttack，不接受单独来弹方向或发射事件冒充攻击。
- 联合行为：同一航迹新鲜火控锁定观测持续至少 2 秒，并存在最近 5 秒内可靠发射武器证据。两类证据均要求分数 >= 0.65、关联 >= 0.8。锁定样本新鲜度 0.5 秒、最大连续观测间隔 0.75 秒。
- 联合判敌原因新增 CombinedBehavior，追加枚举值，不改变已有编号。不把联合行为直接标为已经遭受攻击。
- 已固定友军、敌军不会被这些规则翻转。既有显式人工纠正与撤销接口保留。
- 只有锁定、只有发射、锁定加干扰、旧证据反复读取、跨目标证据不能触发联合判敌。显式纠正后不重新消费纠正之前的行为。
