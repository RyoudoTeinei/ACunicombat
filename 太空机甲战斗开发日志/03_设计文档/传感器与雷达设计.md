# 传感器、告警、电子战与数据链数值设计

> 设计状态：草案。本文只记录玩法和数值结构，尚未写入游戏代码。

## 设计目标

- 玩家操作的是传感器和火控系统，而不是直接读取场景中的真实目标。
- 主动雷达、光电、告警接收机和友军数据链提供不同质量的观测结果。
- 探测、跟踪、识别和武器解算是不同阶段，不使用一个二元“锁定”状态代替全部过程。
- 每种感知手段都必须有代价：主动雷达会暴露，光电缺少可靠距离，电子战会发热并成为辐射源，数据链会延迟或受干扰。
- 数值尽量使用有意义的物理单位；暂时无法物理化的算法能力使用 `0-100` 品质值。

## 目标自身的信号数值

每个目标至少具有以下可变特征：

| 数值 | 单位 | 作用 |
| --- | --- | --- |
| 雷达反射截面 | 平方米 | 决定主动雷达接收到的回波强度，应随观察方向变化 |
| 热辐射特征 | 相对值或瓦特 | 决定红外搜索与跟踪系统的发现距离 |
| 电磁辐射特征 | 相对值或瓦特 | 雷达、干扰机、数据链和其他发射设备工作时上升 |
| 推进器热特征 | 相对值 | 主推进和高强度姿态机动时迅速上升，停机后逐渐衰减 |
| 激光反射特征 | 相对值 | 影响激光测距和激光雷达效果 |
| 当前姿态修正 | 倍率 | 表示不同方向暴露面积、天线和发动机喷口的差异 |

这些数值不是固定“隐身等级”。同一机体在正面滑行、侧面展开武器、主推进器全开时，应呈现完全不同的信号。

## 主动雷达

### 建议记录的装备数值

| 数值 | 单位 | 说明 |
| --- | --- | --- |
| 参考探测距离 | 千米 | 对规定雷达截面、无干扰目标达到发现门槛的距离，不是硬边界 |
| 参考目标截面 | 平方米 | 与参考探测距离配套，防止不同雷达使用模糊标准 |
| 平均发射功率 | 千瓦 | 影响远距离信噪比、耗电、发热和自身暴露 |
| 峰值发射功率 | 千瓦 | 影响脉冲工作能力和被告警系统发现的概率 |
| 天线有效孔径 | 平方米 | 影响增益、波束宽度和测角能力 |
| 工作波段 | 枚举 | 初期可用 `搜索波段`、`火控波段`、`多波段` 三类抽象 |
| 搜索方位角 | 度 | 一次搜索任务覆盖的水平范围 |
| 搜索俯仰角 | 度 | 一次搜索任务覆盖的垂直范围 |
| 波束宽度 | 度 | 越窄则测角更好，但完成大范围扫描需要更多时间 |
| 距离分辨率 | 米 | 区分距离相近目标的能力，越小越好 |
| 角分辨率 | 度 | 区分方向相近目标的能力，越小越好 |
| 径向速度分辨率 | 米/秒 | 区分相对径向速度相近目标的能力，越小越好 |
| 广域搜索刷新率 | 赫兹 | 广域扫描生成新观测的频率 |
| 跟踪扫描刷新率 | 赫兹 | 对已建立航迹进行更新的频率 |
| 单目标跟踪刷新率 | 赫兹 | 集中波束后向火控提供数据的频率 |
| 原始目标容量 | 个 | 雷达前端在一个周期内可以处理的回波数量 |
| 雷达航迹容量 | 条 | 雷达自身能维持的航迹数量，不等于火控容量 |
| 抗干扰品质 | `0-100` | 频率捷变、旁瓣抑制、烧穿和信号处理能力的综合值 |
| 低截获概率品质 | `0-100` | 控制波形、功率和跳频以降低敌方告警概率的综合值 |

### 距离计算原则

参考探测距离只用于标定。实际发现能力至少考虑：

```text
有效探测距离 = 参考探测距离
             × (目标当前雷达截面 / 参考目标截面)^(1/4)
             × 传感器状态修正
             × 干扰修正
             × 环境修正
```

雷达回波随距离的四次方快速衰减，因此目标截面翻倍不会让探测距离翻倍。实际系统不应该在某个距离突然由“完全不可见”变成“精确锁定”，而应通过积累观测逐渐提高航迹置信度。

### 工作模式

| 模式 | 扫描范围 | 更新速度 | 数据质量 | 电磁暴露 | 主要用途 |
| --- | --- | --- | --- | --- | --- |
| 静默 | 无 | 无 | 无主动观测 | 最低 | 依赖光电、告警和数据链 |
| 广域搜索 | 大 | 慢 | 低 | 中 | 发现未知目标 |
| 定向搜索 | 中 | 中 | 中 | 中 | 搜索已知方向或数据链提示区域 |
| 跟踪扫描 | 中 | 中到快 | 中 | 中到高 | 同时维持多条航迹 |
| 单目标跟踪 | 小 | 快 | 高 | 高 | 精确火控和武器发射 |
| 导弹支援 | 定向 | 快 | 高 | 高 | 提供中段更新或持续照射 |

雷达模式会动态改变刷新率、功耗和发热。装备面板记录的是能力上限，不是所有模式同时达到的性能。

## 光电与红外系统

光电系统包括可见光、热成像和红外搜索与跟踪。它们不主动发射电磁波，适合静默探测，但通常先得到方向，不能立即得到可靠距离。

### 建议记录的装备数值

| 数值 | 单位 | 说明 |
| --- | --- | --- |
| 参考热目标探测距离 | 千米 | 对规定热特征目标的发现距离 |
| 参考冷目标探测距离 | 千米 | 对未开主推进器目标的发现距离 |
| 识别距离 | 千米 | 能将目标从光点分类为机甲、导弹或大型载具的距离 |
| 广角视场 | 度 | 搜索模式覆盖范围 |
| 窄角视场 | 度 | 跟踪和识别模式覆盖范围 |
| 角分辨率 | 度 | 测量目标方向的精度，越小越好 |
| 搜索刷新率 | 赫兹 | 广角搜索的刷新速度 |
| 跟踪刷新率 | 赫兹 | 窄角跟踪的刷新速度 |
| 光电航迹容量 | 条 | 能同时维护的被动航迹数量 |
| 红外灵敏度 | `0-100` | 对弱热源和冷目标的综合探测能力 |
| 抗强光品质 | `0-100` | 面对恒星、爆炸、诱饵和发动机尾焰时维持目标的能力 |

### 被动测距原则

- 单次光电观测通常只有方位和俯仰，没有可信距离。
- 连续运动可通过视差和目标角尺寸逐渐估算距离，但需要时间和自身机动。
- 多机从不同位置同时观测，可以利用三角测量迅速改善距离精度。
- 主动激光测距可以直接获得距离，但会触发敌方激光告警。
- 高速接近的导弹即使容易看到，也可能因为发现过晚而没有足够拦截时间。

光电探测强度近似随距离平方衰减，并受到目标朝向、推进器状态、机体散热和背景天体影响。

## 告警系统

告警系统不等于全知提示。它只能根据接收到的辐射或光学迹象推断威胁。

### 雷达与电磁告警接收机

| 数值 | 单位 | 说明 |
| --- | --- | --- |
| 接收灵敏度 | `0-100` | 发现微弱或低截获概率雷达信号的能力 |
| 频段覆盖 | 枚举或列表 | 能监听的雷达和通信波段 |
| 测向精度 | 度 | 估算辐射源方向的误差，越小越好 |
| 更新时间 | 赫兹 | 威胁方向和状态的刷新速度 |
| 辐射源识别品质 | `0-100` | 判断搜索雷达、火控雷达、干扰机和导弹导引头类型的能力 |
| 告警航迹容量 | 条 | 可同时分析和显示的辐射源数量 |

告警等级建议分为：发现搜索信号、疑似跟踪、稳定单目标跟踪、武器照射、主动导引头接近。敌方采用跟踪扫描或低截获概率波形时，告警只能给出概率判断，不保证准确显示“已锁定”。

### 导弹与激光告警

| 数值 | 单位 | 说明 |
| --- | --- | --- |
| 导弹告警参考距离 | 千米 | 对规定发动机热特征导弹的发现距离 |
| 导弹告警覆盖角 | 度 | 机体周围可监视范围，完整覆盖上限为 `360` 度 |
| 导弹告警刷新率 | 赫兹 | 对高速小目标的更新速度 |
| 导弹分类品质 | `0-100` | 区分来袭导弹、碎片和友军弹药的能力 |
| 激光告警灵敏度 | `0-100` | 发现测距、指示和武器激光的能力 |

被动红外导弹不会因为发射动作自动触发雷达告警。玩家只能依赖光电导弹告警系统看到发动机尾焰，或通过友军、目视和战术推断发现威胁。

## 电子战系统

电子战分为电子攻击与电子防护。干扰不是让敌方雷达屏幕直接变黑，而是降低对方观测质量、制造错误航迹或迫使其改变模式。

### 建议记录的装备数值

| 数值 | 单位 | 说明 |
| --- | --- | --- |
| 干扰等效辐射功率 | 千瓦 | 决定噪声干扰在远距离上的强度 |
| 干扰覆盖角 | 度 | 定向阵列或全向天线的覆盖范围 |
| 同时干扰通道 | 个 | 可同时对付的雷达、导引头或通信链路数量 |
| 噪声干扰品质 | `0-100` | 抬高对方接收噪声、压低信噪比的能力 |
| 欺骗干扰品质 | `0-100` | 制造错误距离、速度、角度或虚假目标的能力 |
| 电子防护品质 | `0-100` | 本机雷达和数据链抵抗干扰与欺骗的能力 |
| 频段覆盖 | 枚举或列表 | 能实施干扰的雷达和通信波段 |
| 干扰启动时间 | 秒 | 从识别威胁到生成匹配波形所需时间 |

### 电子战代价与反制

- 干扰机会显著增加耗电、发热和电磁辐射特征。
- 强噪声干扰会暴露大致方向，敌方可以采用被动测向或反辐射武器攻击。
- 距离足够近时，目标雷达回波可能强到能够“烧穿”干扰。
- 雷达可通过缩小波束、提高驻留时间、改变频率、融合光电航迹来抵抗干扰。
- 欺骗干扰成功后应产生可信但逐渐异常的虚假航迹，而不是简单降低一个命中率数值。
- 诱饵、箔条、红外诱饵和拖曳式诱饵属于电子战载荷，但数量应由独立的弹药或消耗品系统记录。

## 数据链

数据链用于共享观测和火控信息。它传输的是带时间戳和误差的航迹，不是同步真实目标坐标。

### 建议记录的装备数值

| 数值 | 单位 | 说明 |
| --- | --- | --- |
| 参考通信距离 | 千米 | 无中继、无干扰、天线方向合适时的稳定通信距离 |
| 带宽 | 兆比特/秒 | 限制同时传输的航迹、图像和武器更新量 |
| 基础处理延迟 | 毫秒 | 编码、融合和排队产生的延迟 |
| 航迹更新率 | 赫兹 | 向友军发送航迹更新的最高频率 |
| 共享航迹容量 | 条 | 可同时接收或发送的目标数量 |
| 武器制导通道 | 个 | 可同时提供中段更新的导弹数量 |
| 抗干扰品质 | `0-100` | 跳频、纠错、定向传输等能力的综合值 |
| 低截获概率品质 | `0-100` | 降低通信被发现和定位概率的能力 |
| 中继容量 | 个 | 可为多少友军或导弹转发数据 |

### 数据链规则

- 航迹包必须包含来源、估计位置、估计速度、误差、置信度和观测时间。
- 接收方需要将通信延迟计入航迹年龄；旧数据不能显示成实时位置。
- 中断数据链后，本机可继续外推友军航迹，但误差会随时间增加。
- 导弹中段更新占用武器制导通道和带宽。
- 多个平台对同一目标的观测可以降低误差，但错误识别也可能通过网络扩散。
- 定向窄波束数据链更难截获和干扰，但要求双方保持天线指向。

## 航迹与传感器融合

航迹不等于真实目标。每条航迹至少包含：

- 估计位置与速度。
- 位置、速度和方向误差。
- 置信度。
- 目标分类与识别置信度。
- 最后观测时间和当前航迹年龄。
- 来源传感器及来源平台。
- 是否受到干扰或存在矛盾观测。

建议保留以下状态：

```text
疑似接触 → 已探测 → 已建立航迹 → 已分类 → 已识别 → 可生成火控解算
```

状态可以倒退。目标关闭推进器、雷达静默、脱离视场或实施欺骗干扰后，航迹应进入外推状态，误差持续扩大，最终丢失。

## 整机数值汇总原则

不同零件组合成整机时不能把所有传感器数值直接相加。

- 质量、耗电、发热、总带宽、干扰功率和独立通道数量可以累加。
- 探测距离、识别距离、刷新率、灵敏度和品质值通常取当前可用设备中的最佳值。
- 角误差、距离误差、延迟等“越低越好”的数值取最低的有效非零值。
- 覆盖角可以由不同方向的阵列组合，但总覆盖不超过 `360` 度，并应记录实际朝向，不能只相加。
- 整机有效航迹数量受传感器航迹容量、火控融合容量和数据链容量中最窄的环节限制。
- 多传感器融合提高的是置信度和抗干扰能力，不应直接把雷达探测距离相加。

## 第一版原型基准

以下仅作为首轮实验的中型机体基准，不代表最终平衡：

| 系统 | 初始基准 |
| --- | --- |
| 主动雷达 | 对 `10 平方米` 目标参考探测距离 `50 千米`；广域搜索 `1 Hz`；跟踪扫描 `4 Hz`；单目标跟踪 `20 Hz`；雷达航迹 `16` 条 |
| 光电系统 | 热目标参考探测距离 `35 千米`；冷目标 `12 千米`；识别距离 `8 千米`；光电航迹 `6` 条 |
| 雷达告警 | 测向误差 `10 度`；刷新 `4 Hz`；告警航迹 `16` 条 |
| 导弹告警 | 对工作中发动机参考距离 `15 千米`；覆盖 `360 度`；刷新 `10 Hz` |
| 电子战 | 同时干扰 `2` 个目标；噪声干扰品质 `50`；欺骗品质 `35`；电子防护品质 `40` |
| 数据链 | 参考距离 `100 千米`；带宽 `8 Mbps`；处理延迟 `50 ms`；航迹更新 `10 Hz`；共享 `32` 条航迹；制导 `4` 枚导弹 |

这些基准的意义是让系统尽快进入可测试状态。实际平衡应根据典型交战距离、机体加速度、导弹飞行时间和玩家可处理的信息量共同调整。
