# 侦查对抗

> 设计状态：玩法草案，尚未进入 Unity 实现。

## 核心规则

- 玩家获得的是航迹，不是真实目标坐标。
- 航迹记录位置、速度、误差、置信度、更新时间和观测来源。
- 侦查结果按 `疑似接触 → 已探测 → 已跟踪 → 已分类 → 火控航迹` 逐级形成。
- 航迹失去更新后继续外推，误差逐渐扩大，最终丢失。
- 进攻方建立确定性；防守方制造延迟、误差和错误判断。

## 雷达对抗

### 进攻方

- 广域搜索：覆盖大，刷新慢，精度低。
- 定向搜索：根据告警、光电或友军提示集中搜索。
- 跟踪扫描：同时维持多条中等质量航迹。
- 单目标跟踪：集中波束，提高刷新率和精度。
- 缩小波束、增加驻留时间，尝试烧穿噪声干扰。
- 切换波形或频段，迫使干扰机重新适配。
- 使用光电和友军侧向观测检查雷达航迹。

### 防守方

- 关闭雷达或使用短时、定向、低功率发射。
- 调整姿态，以较小雷达截面积方向面对威胁。
- 使用噪声干扰降低雷达信噪比。
- 使用欺骗干扰制造错误距离、速度和方向。
- 制造航迹分裂或虚假目标群，消耗敌方跟踪容量。
- 改变速度，使真实目标离开敌方旧预测区域。
- 使用射频诱饵转移雷达或导弹航迹。

### 虚假目标识别

虚假航迹与真实航迹使用相同界面，不直接标记真假。火控持续检查：

- 位置和速度是否连续。
- 加速度是否符合已知推力。
- 加速方向是否对应发动机热源和机体姿态。
- 雷达航迹是否有对应光电或热源。
- 不同友军观察到的位置是否一致。
- 航迹经过遮挡物时是否符合几何关系。

识别状态：

```text
一致 → 存在矛盾 → 疑似欺骗 → 高概率虚假 → 降级或删除
```

高级欺骗系统可以生成符合惯性规律的假航迹，但需要更多功率、处理时间和干扰通道。

### 雷达对抗关键数值

| 进攻方 | 防守方 |
| --- | --- |
| 探测距离 | 雷达截面积 |
| 发射功率和孔径 | 噪声干扰功率 |
| 扫描范围和刷新率 | 欺骗干扰质量 |
| 距离、角度和速度精度 | 射频诱饵特征 |
| 航迹容量 | 同时干扰通道 |
| 抗干扰品质 | 电子暴露和产热 |

## 光电对抗

### 进攻方

- 使用可见光、热成像和红外搜索进行静默探测。
- 广角模式搜索，窄角模式识别和跟踪。
- 根据目标角尺寸、连续运动和视差估算距离。
- 使用多机三角测量提高被动测距精度。
- 用热源和可见轮廓验证雷达航迹。
- 使用主动激光测距直接获得距离，但会触发激光告警。

### 防守方

- 减少主推进器工作，降低新增热辐射。
- 控制散热器展开和高温表面朝向。
- 利用大型物体、残骸和高热背景遮挡。
- 释放红外诱饵或主动光学诱饵。
- 使用强光、爆炸和发动机尾焰增加光电识别难度。
- 在诱饵释放后改变运动方向，使本体与诱饵分离。

### 光电规则

- 单机被动光电首先获得方向，距离误差较大。
- 热特征随推进、武器和散热状态变化。
- 停止推进后热量不会立即消失。
- 红外导弹发射不会自动触发雷达告警。
- 导弹告警系统必须实际发现导弹热源或光学特征。

### 光电对抗关键数值

| 进攻方 | 防守方 |
| --- | --- |
| 热目标与冷目标探测距离 | 热辐射特征 |
| 识别距离 | 推进器热特征 |
| 广角和窄角视场 | 散热器状态 |
| 角分辨率和刷新率 | 红外诱饵强度 |
| 光电航迹容量 | 光学干扰质量 |
| 红外灵敏度 | 当前姿态和遮挡 |

## 电子战

### 分类

| 类型 | 作用 |
| --- | --- |
| 电子支援 | 截获、识别和测向雷达、干扰机及数据链信号 |
| 电子攻击 | 压制或欺骗雷达、通信、数据链和导弹导引头 |
| 电子防护 | 在干扰环境中维持己方传感器、通信和武器工作 |

### 进攻方

- 被动测向敌方雷达和干扰源。
- 使用噪声干扰降低敌方搜索和跟踪距离。
- 使用欺骗干扰制造虚假航迹。
- 干扰敌方数据链，降低共享航迹和导弹更新率。
- 定位中继或支援干扰机，优先攻击关键节点。
- 使用向干扰源归航武器攻击持续辐射源。

### 防守方

- 使用雷达告警判断搜索、疑似跟踪、武器照射和导引头接近。
- 对威胁分配有限干扰通道。
- 使用频率捷变、定向链路和多传感器融合抵抗干扰。
- 在强干扰、间歇干扰和静默之间切换。
- 切断敌方母机、友军和导弹之间的数据更新。
- 在链路受污染时切换本地自治，避免错误航迹扩散。

### 强干扰源定位

- 强干扰会暴露辐射源方向。
- 单机首先得到方向扇区，不能直接获得精确距离。
- 干扰越强、持续越久，测向误差收敛越快。
- 两台分离友军共享方向扇区后，可以交叉定位干扰源。
- 定位结果必须考虑观测时间差和干扰源运动。
- 间歇或定向干扰降低暴露，但会留下雷达恢复窗口。

```text
友军 A 测向 ─┐
              ├→ 交叉区域 → 干扰源概率位置
友军 B 测向 ─┘
```

### 多机数据链

数据链传输带来源、时间戳、误差和置信度的观测包，不传输真实目标坐标。

可实现：

- 被动交叉定位雷达和干扰源。
- 多机光电三角测距。
- 一机主动搜索、其他友机静默接收。
- 多视角检查虚假航迹。
- 接力跟踪离开本机视场的目标。
- 由其他友机继续更新已经发射的导弹。

限制：

- 延迟使共享航迹落后于真实目标。
- 带宽不足会降低航迹刷新率。
- 两个目标可能被错误合并或重复编号。
- 一台受骗友机可能向整个编队传播虚假航迹。
- 中继被摧毁或干扰后，编队会分成信息孤岛。
- 全向高功率数据链容易被发现和干扰。
- 友军支援干扰也可能影响己方链路。

### 电子战关键数值

| 数值 | 作用 |
| --- | --- |
| 接收灵敏度和测向精度 | 发现并定位辐射源 |
| 辐射源识别品质 | 判断搜索、跟踪、干扰和导引头信号 |
| 干扰功率和覆盖角 | 决定压制范围和方向 |
| 噪声与欺骗品质 | 决定航迹降级或虚假程度 |
| 干扰通道数量 | 限制同时处理的威胁 |
| 电子防护品质 | 抵抗干扰和欺骗 |
| 数据链带宽、延迟和更新率 | 决定协同航迹质量 |
| 数据链抗干扰品质 | 决定受压制时的可用性 |
| 电磁特征、耗电和产热 | 电子战工作的代价 |

## 进攻与防守流程

| 阶段 | 进攻方 | 防守方 |
| --- | --- | --- |
| 搜索 | 雷达、光电、被动测向 | 静默、降低雷达与热特征 |
| 建立航迹 | 定向搜索、多机融合 | 欺骗、改变姿态和速度 |
| 稳定跟踪 | 单目标跟踪、光电确认 | 噪声干扰、假目标、遮挡 |
| 火控解算 | 提高刷新率、缩小误差 | 强机动、数据链干扰 |
| 导弹中段 | 母机或友军更新 | 切断链路、改变加速度 |
| 导弹末段 | 导引头搜索和分类 | 干扰、诱饵、机动、点防御 |

## 玩家资源

- 电磁暴露。
- 功率和热量。
- 雷达、火控、干扰和制导通道。
- 数据链带宽。
- 航迹更新时间。
- 诱饵数量。

## 第一版原型

- 雷达：广域搜索、跟踪扫描、单目标跟踪。
- 光电：广角搜索、窄角跟踪、被动方向航迹。
- 电子战：雷达告警、噪声干扰、欺骗干扰、数据链干扰。
- 航迹：误差、置信度、更新时间、来源和物理一致性。
- 多机：一个友军传感器节点，支持测向交叉定位和航迹共享。
- 武器：一种具有中段数据链和末段主动雷达的导弹。
- 防御：射频诱饵、红外诱饵和静默模式。

## 设计限制

- 不使用万能干扰按钮。
- 不把干扰等同于解除锁定。
- 不把告警当作读取敌方锁定变量。
- 不直接标记虚假目标。
- 不用固定随机概率判定诱饵成功。
- 不让数据链提供无延迟、无误差的真实坐标。
