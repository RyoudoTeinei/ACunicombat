# 角色动作导入研究

## 当前结论

- `AC6_ExtractedAssets/chr` 下的角色 FBX 通常包含骨架和蒙皮，但不包含可直接播放的 Action。
- 已抽查：
  - `ALLMIND - c4201/c4201.fbx`：10 个 mesh，1 个 Armature，838 根骨头，0 个 Action。
  - `AC4 AC - c8110/c8110.fbx`：3 个 mesh，1 个 Armature，0 个 Action。
  - `Balteus - c4100/c4100.fbx`：25 个 mesh，1 个 Armature，0 个 Action。
- `chr/AC - c0000` 中存在大量 `.hkx` 和 `.bhv`，其中 `.hkx` 头部显示 `SDKV20190100` 与 `hkaAnimationContainer`，说明原始动作大概率是 Havok 2019 动画容器。
- Unity 和 Blender 不能直接把这些 `.hkx/.bhv` 当成普通动画导入；真正导入 AC6 原动作需要额外的 Havok 动画转换步骤。

## 已跑通的验证管线

- 新增 Blender 脚本：`ACunicombat/Tools/Blender/ExportAC6RiggedTestAnimation.py`。
- 该脚本从 `ALLMIND - c4201/c4201.fbx` 读取骨架，生成一个短的测试动作 `AC6_C4201_Test_MechReady`，再导出为 Unity 可读取的 FBX。
- 输出位置：
  - `ACunicombat/Assets/_Project/ImportedFromExtracted/Animations/AC6_C4201_TestAction.fbx`
  - `ACunicombat/Assets/_Project/ImportedFromExtracted/Animations/AC6_C4201_TestAction_manifest.json`
- 已用 Blender 读回验证：导出的 FBX 包含 1 个 Armature 和 1 个 Action。
- 新增 Unity 菜单：`Tools > ACunicombat > Animation > Import AC6 Rigged Test Animation`。
- Unity 菜单会把测试 FBX 配置为 Generic 动画，并生成 Animator Controller 与预览 prefab。

## 设计判断

- 角色动作导入和材质/武器烘焙不是同一个难度级别。材质烘焙只需要解释贴图和 shader；原动作导入需要解析 Havok 动画数据。
- 当前换装系统是分部件装配，适合做“模块 Transform + 挂点 + 程序动画”。如果直接使用完整角色骨架动画，需要解决部件如何绑定到统一骨架的问题。
- 对太空机甲战斗来说，核心运动更适合程序化：姿态控制、推进器喷口、武器瞄准、后坐力、手臂跟随、背武器展开都应该响应当前速度和目标方向，而不是完全依赖固定动作片段。
- AC6 原动作可以作为参考或部分姿态来源，但项目中期应优先建立自己的机体动画层。

## 当前动画层拆分

- 完整骨架预览层：`AC6_C4201_TestAction_Preview`，用于证明 Unity 可以播放带骨架 FBX 动作。
- 模块化换装机体层：`MechProceduralPoseAnimator`，用于驱动当前 `MechAssembler` 拼出的部件。
- 这两层不是同一个对象。完整骨架预览机能播放 Animator，不代表换装机体会自动继承动作；换装机体需要自己的槽位姿态、IK、挂点和武器逻辑。

## DSAnimStudio 5.0-RC6.1 调研

- 已下载并解压 DSAnimStudio 5.0-RC6.1 到 `E:/UnityDev/Tools/DSAnimStudio/DSAS-V5-RC6.1`，对应源码解压到 `E:/UnityDev/Tools/DSAnimStudio/DSAS-ver5.0-rc6.1-source`。
- 该版本 release note 明确出现 `AC6` game tag，并且源码中包含 `Res/TAE.Template.AC6.xml`、`ShaderConfig/AC6`、`Res/UxmDict/AC6.txt`、`IngameReload_AC6.ini` 等 AC6 支持文件。
- DSAnimStudio 的 `Tools > Export Skeleton & Animations...` 可以批量导出骨架和动作，但导出目标是 Havok 格式：`Havok 2010.2 XML`、`Havok 2010.2 Packfile x32`、`Havok 2016.1 Tagfile x64`。
- 源码中没有发现 HKX 到 FBX/glTF 的直接导出路径。FBX 相关功能主要是反方向：`SapImportFbxAnimForm` 将 FBX 动画导入并转换成游戏用 HKX，且当前导入限制在 DS1/DS1R/DS3。
- 因此 DSAnimStudio 可以作为 AC6 原动作读取、预览、导出 Havok XML 的中间工具；它不是可直接把 AC6 动画变成 Unity FBX 的一键转换器。
- 可行管线应改为：AC6 HKX -> DSAnimStudio 导出 Havok XML -> 我们解析 XML 中的骨骼轨道 -> 生成 Unity `AnimationClip` 或中间 JSON -> 绑定到项目自己的统一机体骨架/程序动画层。
- DSAnimStudio 5.0-RC6.1 需要 `.NET 9` Windows Desktop runtime；当前机器 `dotnet --info` 只检测到 `.NET 6.0.36`，运行 GUI 前需要安装或放置便携版 `.NET 9` runtime。
