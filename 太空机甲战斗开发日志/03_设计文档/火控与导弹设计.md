# 火控与导弹设计

## 火控状态

- `Detected`：发现疑似目标。
- `Tracked`：航迹稳定，能估算位置和速度。
- `Fire Solution`：火控电脑能生成拦截解算。
- `Weapon Lock`：武器自身 seeker 有能力接管目标。

## 火控原则

- 玩家锁定的是航迹，不是真实物体。
- 航迹质量越高，拦截解算越稳定。
- 允许低质量解算发射，但导弹可能搜索不到目标或中段误差过大。

## 导弹制导阶段

### 发射前

母机火控提供初始目标航迹和拦截估计。

### 中段

导弹使用惯性导航飞向预测拦截区域。若数据链可用，母机可以更新目标航迹。

### 末段

导弹打开 seeker，在视场和距离内自主搜索并锁定目标。

### 失败条件

- 目标离开 seeker 视场。
- 目标信号不足。
- 导弹燃料耗尽。
- 导弹机动能力不足。
- 母机航迹质量过差。
- 干扰或诱饵导致 seeker 误判。

## 当前实现

- 阶段：发射延迟、冷弹射、安全离架、姿态对准、助推、中段惯性、导引头搜索、末段制导、无制导惯性。
- 初始速度：继承发射机体的完整世界速度；右肩空空导弹沿发射方向增加默认 `40 m/s`，左肩拦截弹严格沿筒轴增加默认 `55 m/s` 弹射速度。
- 主发动机：默认以 `300 m/s²` 燃烧 `3.5 s`，相对发射机体增加约 `1090 m/s`；不设置世界系总速度上限。
- 滑行：燃烧结束后关闭尾焰并保持惯性速度，不做空气阻力或人为降速。
- 火控解算：使用“载机速度 + 弹射段 + 定加速度助推段 + 关机滑行段”的分段运动模型；目标与载机的共同世界速度不会改变预计交会时间。
- 中段：消费母机公开航迹和制导通道，不读取目标场景对象。
- 导引头：独立仿真实体与 `SensorId`，以 `20 Hz` 发射最高优先级窄波束驻留。
- 测量：距离、方向、多普勒、LOS 率和信噪比；测量不包含目标实体 ID。
- 交接：按火控给出的开机时刻和搜索篮关联测量；捕获后释放母机制导通道。
- 制导：中段低权限修正，末段使用 PN；侧向加速度、转弯率和机动 `Delta-V` 均有限。
- 引信：发射后时间和安全距离双重解除保险，以相对运动 CPA 判断近炸。
- 战斗部：近炸半径与杀伤半径分离，杀伤随爆距衰减。
- 未实现：弹载雷达抗干扰、诱饵分类、破片锥方向性、遮挡和多目标本地航迹。

## 左肩拦截弹冷发射设计

> 状态：首轮运行代码已实现，参数仍需试玩调整。

左肩拦截弹采用类似垂直发射防空导弹的冷发射流程，强调弹体必须先安全离架，再通过姿态控制系统转向，最后启动主发动机。发射动画和运动状态必须对应真实的动力来源，不允许在生成瞬间直接把弹头朝向拦截点。

### 发射阶段

1. **沿筒轴弹射**
   - 弹体初始姿态严格继承发射筒轴线。
   - 初始世界速度为“机体世界速度 + 沿筒轴的弹射速度”。
   - 弹射器只提供离架速度，不提供朝向目标的侧向速度。
2. **安全离架**
   - 主发动机保持关闭，弹体按惯性继续运动。
   - 必须同时满足最短离架时间和相对发射架的最小距离，才允许开始大角度转向。
   - 安全距离应按弹体相对机体的位移计算，不能用双方共同的世界速度虚增离架距离。
3. **姿态发动机转向**
   - 火控给出的预测拦截点只决定目标姿态，不直接改变速度方向。
   - 弹体使用 RCS 姿态喷口产生角加速度，转动受转动惯量、喷口推力、力臂、最大角速度和姿态推进剂限制。
   - 转向时弹体原有平移速度基本不变，因此弹头朝向与运动方向可以暂时不同。
   - 前后成对喷口应显示短促喷流，使画面能看出实际施加的转动力矩。
4. **主发动机点火**
   - 弹体与预测拦截方向的夹角小于点火容差后，主发动机点火。
   - 主发动机推力始终沿弹体当前纵轴施加，点火后才开始显著改变速度向量。
   - 设置最长姿态调整时间作为故障保护；当前原型在超时后强制点火，后续可根据试玩改为继续调整或自毁。

### 初始建议参数

| 参数 | 建议初值 | 说明 |
| --- | ---: | --- |
| 弹射速度 | `55 m/s` | 相对发射架，严格沿筒轴 |
| 最短安全离架时间 | `0.12 s` | 防止刚生成即转向或点火 |
| 最小安全离架距离 | `5 m` | 按弹体相对机体的轴向位移计算 |
| 主发动机点火角容差 | `8°` | 弹体纵轴与预测拦截方向的夹角 |
| 姿态调整超时 | `0.6 s` | 暂定，仅作为原型保护参数 |

这些数值只用于首轮原型，不作为最终平衡值。安全距离应结合左肩发射筒长度、机体碰撞体、弹体尺寸和最大姿态角速度共同调整。

### 与右肩空空导弹的区别

- 左肩拦截弹使用完整的“弹射、离架、转向、点火”冷发射流程。
- 右肩空空导弹暂时保留现有发射逻辑，不因左肩方案自动改为冷发射。
- 两者可以共用火控航迹、分段动力学和导引头框架，但发射状态机必须分别配置。

### 当前实现说明

- 玩家与 AI 的左肩拦截弹均严格使用发射筒轴线作为生成姿态和弹射速度方向。
- 安全离架要求同时满足 `0.12 s` 和 `5 m`；距离使用弹体与发射机体的逐帧实际位移差计算，不受双方共同世界速度影响。
- 安全离架后，预测拦截点只作为目标姿态；RCS 通过有限推力、转动惯量、力臂、角速度和推进剂完成转向。
- 姿态转向期间不直接修改平移速度，因此弹体朝向与运动方向可以分离。
- 对准误差小于 `8°` 或姿态调整超过 `0.6 s` 后，主发动机点火并沿弹体纵轴施加推力。
- RCS 粒子系统会按实际平移指令或转动力矩选择喷口；主发动机粒子和尾迹在点火前保持关闭。
- 右肩空空导弹未启用冷发射参数，继续使用原有发射流程。
