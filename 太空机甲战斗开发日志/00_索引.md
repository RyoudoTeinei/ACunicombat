# 太空机甲战斗游戏开发日志

这个目录用于记录实验性 Unity 项目的设计、待办、实现进度、测试反馈和关键决策。

写入或生成日志前，先阅读 [开发日志写入接口](./AGENTS.md)。符合接口格式的 Markdown 会被资料库网页自动发现。

## 项目一句话

一款以太空为背景的机甲战斗游戏，核心不是传统游戏锁定，而是用传感器、航迹、火控解算和武器自身制导构成战斗系统。

## 目录结构

- `01_待开发事项/`：待开发事项、功能拆分、优先级。
- `02_已开发内容/`：已经完成的功能、变更记录、实现说明。
- `03_设计文档/`：玩法、机体、传感器、火控、导弹、世界观等设计。
- `04_研究与参考/`：技术调研、参考问题、拟真方向资料整理。
- `05_决策记录/`：已经拍板的设计和技术决策。
- `06_测试与试玩记录/`：试玩记录、手感反馈、平衡性问题和复现步骤。

## 推荐记录习惯

- 每完成一个功能，更新 `02_已开发内容/变更记录.md`。
- 每出现一个新的想法，先放进 `01_待开发事项/`，不要直接塞进实现。
- 每次确定一个方向，写入 `05_决策记录/决策日志.md`，避免反复摇摆。
- 每次试玩后，更新 `06_测试与试玩记录/试玩记录.md`。
