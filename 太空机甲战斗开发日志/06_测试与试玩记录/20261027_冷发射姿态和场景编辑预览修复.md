# 冷发射姿态和场景编辑预览修复

## 冷发射

原逻辑让所有冷发射导弹在安全分离后进入 AttitudeAlignment，先对准远期预测拦截点再点火。它没有写死转到 90 度，但预测点偏上时空空弹会在点火前大幅抬头。

现在前向冷发射空空弹保持弹射轴，通过原有分离时间和距离检查后点火，随后按正常制导转向。拦截弹的预点火对准流程保留。弹射角度、抛射速度及分离门限未在本次修改。

## 场景编辑

用户确认使用主菜单“开始场景”。真实菜单到战场的配置加载测试正常；发现编辑地图的 PresentationPosition 将 Own 联系人固定到地图宿主原点，忽略文档中的玩家位置。已有保存配置的玩家已移动到约 (-54.96 km, 0, -31.99 km)，预览却仍显示原点，导致预览、点选和开局相对位置不一致。

场景编辑模式现直接使用配置坐标；实时战场仍使用本机导航位置。编辑页新增保存/启动结果提示，提示区屏蔽地图拖动，避免错误被提前 return 隐藏。本次最终改动不包含直接 Play 自动加载保存配置的试探方案。
