# AC6 热成像视野实现（`~ 键，白热/黑热）

日期：2026-07-25

解决"黑机体对黑太空看不清远处目标"：战争雷霆式黑白热成像。核心决策是**热信息
是 sim 层数据、成像交给 GPU 渲染管线**——不是后处理滤镜（黑对黑的 RGB 里没有
信息可反推），也不是逐目标 CPU 射线检测（那是雷达的做法且贵）。

## 1. 架构

```
热源事件（节流/AB/QB/开火，全部现成信号）
   → MechThermalSignature 一阶热模型（按通道：蒙皮/推进器/左手/右手）
   → MaterialPropertyBlock 逐 renderer 注入 _ThermalTemp
   → [AC6ThermalObjects] RenderObjects feature 用热辐射材质重画不透明场景
   → [AC6ThermalScreen] FullScreenPass feature：冷背景/噪声/像素化/极性
   ← MechThermalVisionController：`~ 循环模式、CPU 端 AGC、自动补挂热源
```

- **与 07-21 热资源决策同源**：推力越狠→温度越高→热像里越亮。将来的红外导引头
  /IRST 读同一组 `GetChannelTemperature`，玩家所见与导弹"所见"一致，热诱饵/
  冷却机动自动对两者同时生效。
- **遮挡、视线、距离衰减由渲染免费解决**：热视野本质是一台相机。
- **两个 feature 都是 URP 内置类**（RenderObjects / FullScreenPassRendererFeature），
  没有自定义 RenderGraph pass，Unity 6 兼容性风险最小。

## 2. 文件

| 文件 | 职责 |
| --- | --- |
| `Shaders/AC6ThermalRadiance.shader` | override 材质：L=ε·(T/1000)⁴ → AGC 窗口映射灰度；掠射角发射率衰减勾勒轮廓 |
| `Shaders/AC6ThermalScreen.shader` | 深度==far 判太空→冷底；探测器像素块量化+时域噪声；黑热在此唯一反转 |
| `Mech/Runtime/MechThermalSignature.cs` | 四通道一阶热模型；加热 τ=1.2s、真空冷却 τ=6s（热惯性=刚机动完的目标持续显眼）；按装配记录把 Booster/左右手武器 renderer 绑到对应通道 |
| `Mech/Runtime/MechThermalPointEmitter.cs` | 恒温点源（目标机 330K、导弹 620K） |
| `Mech/Runtime/MechThermalVisionController.cs` | 模式循环、feature 开关、CPU AGC（遍历注册表求温度域→辐射窗口推 shader 全局量，无 GPU 回读）、0.5s 周期给未标记目标/导弹补挂点源 |
| `Editor/AC6ThermalVisionInstaller.cs` | 菜单一键装 feature+建材质，幂等 |

## 3. 接线（零场景重建）

- `MechPlayerInputAdapter`：`backquoteKey` 边沿 → `ThermalVisionCycleEdge`。
- `MechPlayerRig.Awake`：自动补挂 `MechThermalSignature`（喂 motion）与
  `MechThermalVisionController`；Update 处理 `~ 循环；开火边沿调
  `NotifyWeaponFired`（主/副=左/右手，肩部计对应侧）；右侧仪表盘加 THERMAL 行。
- 喷焰特效在透明队列、于热重画之后叠加——热羽流免费获得。
- AGC 窗口自适应当前场景温度域（0.35s 平滑），远处微弱目标自动拉进灰阶，
  这是真实 FLIR 的工作方式。

## 4. 使用步骤

```text
1. 打开 Unity 等编译完成
2. Tools > ACunicombat > AC6 > Install Thermal Vision （一次即可）
3. Play，`~ 键循环：关闭 → 白热 → 黑热
```

## 5. 已知近似与替换路径

| 近似 | 替换 |
| --- | --- |
| 未标记物体统一 240K（材质默认值） | 按 `ac6_frame_material_catalog.json` 材质类别配发射率/基线温度 |
| 目标机/导弹恒温点源 | 给 AI 机体挂完整 MechThermalSignature（读它自己的 motion） |
| 太阳不特殊处理（背景统一冷底） | 屏幕 pass 按太阳方向画饱和白点 + 镜头眩光 |
| 热模型只做显示 | 并入热资源系统（过热惩罚），温度状态发布进 SimWorld 供 IR 导引头 |
| 视野关闭时热模型仍在积分 | 若剖析显示可见成本，按 Mode 门控 MPB 推送 |
