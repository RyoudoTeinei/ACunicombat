# AC6 战斗演示与材质验证日志（2026-07-15）

> **2026-07-17 修正声明：** 本文第 4、7 节对“飞行、QB、远程开火已通过”的结论无效。后续视觉复核确认，当前场景只在移动机体根节点，机体始终播放同一条 `a000_010900`；远程开火只驱动武器自身，没有切换或叠加机体抬臂动作；喷焰方向也未经过世界空间验证。批处理测试仅检查阶段日志和装备动作是否触发，不能证明最终画面正确。完整问题见 `Docs/AC6战斗演示机体动作与喷焰方向缺口_咨询日志.md`。

## 1. 目的

建立一个可直接播放的 Unity 验证场景，集中检查机器人移动、飞行、Quick Boost、右手武器开火、背部导弹发射、近战武器动作及对应特效通道。场景使用已经通过换装验证的 `Uniform1010`，不引用 Blender 烘焙模型或旧 Unity 烘焙材质。

## 2. 场景与入口

- 场景：`Assets/_Project/LocalSamples/AC6SkinnedModular/Generated/Scenes/AC6CombatShowcase.unity`
- 重建菜单：`Tools > ACunicombat > AC6 > Build Combat Showcase`
- 进入 Play 后每阶段约 4 秒，七阶段循环播放。

## 3. 七阶段内容

1. `HoverLaunch`：原 HKX 推进器动作 + 垂直起飞位移 + 尾焰。
2. `ForwardFlight`：原 HKX 推进器动作 + 运行时前向飞行轨迹。
3. `QuickBoost`：推进器 `a000_000002` + 横向快速位移 + 爆发尾焰。
4. `RangedWeaponFire`：右手武器原始动作 `a000_800210` + dummy 枪口爆发。
5. `MissileLaunch`：两具背部导弹舱播放原始装备动作，共发射 6 枚运行时制导弹体。
6. `PileBunkerFire`：左手打桩机原始动作 `a000_040010` + TAE 特效时间线。
7. `Recovery`：推进器 `a000_000003` + 返回初始位置。

本体和装备关节动作来自原始 HKX。机器人根节点飞行路径、目标运动、导弹制导和弹体飞行属于游戏逻辑，因此由运行时模拟，不应烘进角色动作。

## 5. 特效边界

TAE 到特效事件的路由已经接入，`AC6FxrEffectFactory` 也能从解析后的 FXR JSON 构建 URP 粒子预制体。但本机当前没有 `Tools/LocalOut/fxr_json`，生成的 `MechEffectPrefabLibrary` 含 0 个原 FXR 预制体。因此当前场景可见的尾焰、枪口焰、导弹尾迹和命中爆发是明确标注的诊断占位特效，不是原版 AC6 FXR 的完整还原。

要验证原特效，下一步必须先从游戏资源导出 FXR JSON 和所需纹理，再运行 FXR 构建器；不能把当前占位粒子当作特效管线已完成。

## 6. 贴图与颜色结论

`Docs/AC6生素材导入管线.md` 已记录颜色问题：肢体与武器都走 `AC6PartToGltf` 原生 FLVER/HKX/DDS 管线，基础色、法线、发光和 Marking 能随 GLB 导入；中性灰装甲并不是 Blender 与原生管线不同造成的。

本次运行时实测为 32 个材质槽中 18 个具有基础贴图。剩余外观仍偏银灰的主要原因是 AC6 的 `_3m` Zone 掩码、区域颜色调色板和 matbin 参数尚未在当前原生 GLB 材质上重建。旧 `AC6ModularPartsImporter` 虽有近似 Zone shader 参数代码，但本验证场景不走旧导入器，不能据此宣称颜色已经恢复。

交接日志提到的 `Resources/game/material/allmaterial.matbinbnd.dcx` 在本机 `E:/UnityDev/Resources` 和工程内均未找到。完整颜色还原需要补齐该游戏本体资源并实现 matbin/Zone 到 Unity shader 的映射。

## 7. 当前结论

- 动画、换装装备播放器、移动、飞行、QB、远程开火、导弹与近战演示：已跑通并通过自动验证。
- 特效触发时序：已接入；原版 FXR 资源：本机缺失，目前使用诊断占位特效。
- 基础贴图：部分成功绑定；原版区域涂装与颜色：尚未完成。
