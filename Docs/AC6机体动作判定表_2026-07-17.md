# AC6 机体动作判定表（c0000）

日期：2026-07-17

方法：本机 `Resources/Game` 解包数据的三源交叉——(1) `AC6AnimExportProbe --dump-tae` 的全量 TAE 转储（`Tools/LocalOut/c0000_tae_dump.json`，53 个 bank）；(2) `AC6HkxPoseExporter` 批量导出 254 条 a000 动作的全采样姿态后做运动学分类（时长/根骨速度/偏航/手臂-腿-躯干活动量/循环误差/躯干倾斜）；(3) `ThrustersParam_PC` 参数字段词汇。未使用任何按文件名范围的猜测。

## 1. 基础设施级结论（确定）

1. **TAE 条目的 `name` 字段就是 anim ID → HKX 文件的官方映射**。例如 TAE ID 11030 → `a000_105030.hkt`、TAE ID 22200 → `a000_004220.hkt`。旧咨询"alias/mini-header 映射未解"问题就此闭合：直接读 TAE 转储的 name 列即可，不存在按文件名一一对应的假设。
2. **AC6 机体动作全部是原地动画**：254 条样本的根骨（Master）位移几乎全为零，位移由引擎/行为层驱动。这证实了 showcase 控制器"根轨迹 = 玩法模拟"的架构定性——缺的是姿态 Clip 层，不是根运动层。
3. **`ThrustersParam_PC` 的字段前缀就是官方推进状态机词汇**：`main / subFront / subBack / subLeft / subRight / qbFront / qbBack / qbLeft / qbRight / lift / …`，每状态一组 SFX 槽位（SlotNO 1-4 对应 TAE 里 `SpawnOneShotFFX` 事件的 SlotID 与机体 DummyPoly 2014/2031/2034/2150）。
4. **手臂武器动作按武器类别分 bank**：`5000200_a200.tae` 到 `5000331_a331.tae` 共 30+ 个 bank，每个 bank 实现同一套动作槽模板（见第 3 节）。HKX 在对应的 `c0000_a2xx_yy.anibnd.dcx`。
5. `5000000_a00.tae` 与 `5000001_a000.tae` 内容完全相同（631 条），实现时任取其一。

## 3. a2xx 武器手臂动作槽模板（每 bank 通用）

以 a200/a201/a211 实测归纳，ID 为 bank 内 TAE anim ID：

| 槽 | 判定 | 证据 |
| --- | --- | --- |
| `030x20` | 持枪/抬臂·进入 | 41 事件、Blend 开头 |
| `030x21` | 进入的短变体 | ≤1 事件 |
| `030x22` | 持枪保持·循环 | 44-45 事件、可循环 |
| `030x24` | 收枪/放下 | Type155+Type767 组合 |
| `030x30 / 030x50` | **开火/执行**（含后坐） | RumbleCam_Global + Type19 |
| `031xxx / 032xxx` | 第二/第三动作组（蓄力/连发/武器技嫌疑） | 同构模板重复 |

`030x2x` 与 `030x4x` 为左右手镜像组。x = 0/1/2 随 bank 增加为姿态变体。**这些就是 `MechBodyActionPlayer` Layer 1（上半身遮罩层）的原生素材。** 剩余未解：武器类别 → bank 编号的映射表（在 `EquipParamWeapon` 或武器行为参数里，本机缺该 paramdef，见第 4 节）。

## 4. 剩余验证项（收尾级，不阻塞接线）
