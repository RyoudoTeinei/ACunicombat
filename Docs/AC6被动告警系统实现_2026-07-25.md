# AC6 被动告警系统（RWR/ESM）实现

日期：2026-07-25。路线：**纯物理**——告警是一台只收不发的被动传感器，消费
`EmissionEvent`，不读辐射方任何模式标志。音频为占位槽。

## 1. 链路

```
任何主动辐射（ProcessDwell 已写 EmissionEvent 环）
  → EsmReceiverSystem（Sensors）：主瓣/旁瓣几何 + 单向 1/R² + 阈值概率检测
  → WarningObservation（既有契约，设计文档 12）：带噪方位+频段+波形+功率，无距离
  → EsmThreatCorrelator（Tracking）：频段+方位聚类 → 波程结构统计 → 级别涌现
  → ThreatSnapshot → MechThreatWarningPresenter（左下 RWR 方位环 + 分级音频）
```

## 2. 两个关键机制

**电子战不对称免费成立**：RWR 收到的是单程功率（20·log10 R），对方雷达回波是
双程（40·log10 R）——告警距离天然远超对方探测距离，不需要任何特判。默认参数下：
主瓣 100 km 可闻，旁瓣（−28 dB）约 10-18 km 可闻，都由数值而非代码决定。

**级别从波程结构涌现**（不是裸照射间隔——搜索波束扫过也会连给 2~3 条短间隔
接触，只看间隔会误报锁定）：

| 观测到的结构 | 级别 |
| --- | --- |
| 短照射（~0.08s）+ 长重访（~3s 搜索帧） | Spiked（被扫描） |
| 单驻留 + ~0.24s 重访（对方 TWS 在重访你） | Tracked（对方已建你的航迹） |
| 连续照射累计 ≥0.5s（STT 驻留率下 gap ≤0.15s 不断档） | Locked |
| 导引头波形（波形库查表） | MissileActive（pitbull） |

升级即时、降级带 0.6s 滞回逐档回落；照射中断 >0.15s 清零连续照射证据。
对欺骗天然诚实：AI 想装 STT 就得真的提高驻留率，想静默就得真关雷达。

## 3. 文件与接线

| 文件 | 内容 |
| --- | --- |
| `Sim/Contracts/ThreatSnapshot.cs` | `EsmThreatLevel/EsmWaveformClass/EsmThreatId/ThreatSnapshot`（匿名纪律：无距离无真值身份） |
| `Sim/Sensors/EsmReceiverSystem.cs` | `EsmReceiverProfile` + 接收系统；哈希链种子确定性掷骰；测向噪声 8°（1σ） |
| `Sim/Tracking/EsmThreatCorrelator.cs` | 16 槽辐射源、波形库表、波程统计分类、Handle 世代号 |
| `SimulationDriver` | 每传感器 Tick：radar.Tick → tracker → **esm.Tick(radar.Emissions) → correlator**（发射环每 Tick 清空，接收必须同 Tick）；API：RegisterEsmReceiver / RegisterEsmWaveformClass / CopyThreats / TryGetHighestThreat |
| `MechRadarController` | 注册本机接收机（消隐本机雷达 EmitterId；**本机导弹导引头照样被自己听到**——真实 RWR 分不清敌我辐射）；波形库登记 (1,1)=火控 (1,2)=导引头 (1,3)=搜索；`autoEquipTestEmitters` 给发现的目标自动补挂测试辐射源 |
| `MechTestRadarEmitter.cs` | 目标机测试雷达：360° 圆扫（120°/s，波形 3）；玩家进 8 km 切对玩家高驻留照射（波形 1）→ 完整演示 Spiked→Tracked→Locked 升级；SensorId 从 63 向下分配（导弹导引头从 1 向上，共用 64 槽） |
| `MechThreatWarningPresenter.cs` | 左下 RWR 环（机头朝上，方位基准=飞控逻辑航向，与战术图一致）；S/T/L/M 分级符号，锁定级以上闪烁；**音频占位**：4 个 AudioClip 槽（扫描单响/跟踪单响/锁定循环/导弹循环），为空静默，资产到位拖入即可 |
| `MechPlayerRig` | 有雷达时自动补挂 presenter（零场景重建） |

## 4. 已知近似与 P2/P3 路径

| 近似 | 替换 |
| --- | --- |
| 波形识别置信度恒 1 | 按接收信噪比打折（WarningObservation.WaveformConfidence 已预留） |
| 波形库 3 条硬登记 | 数据文件化（威胁类型/预估射程/告警优先级） |
| 测试辐射源水平面圆扫 | AI 行为化（静默接近、假锁定恐吓——机制已天然支持） |
| 辐射源满 16 丢弃新源 | 按威胁度淘汰 |
| 无红外通道 | MAW：广角 IR 传感器读 MechThermalSignature/点热源 + AnalyticOcclusion（补 IR 弹/ARH 中段的静默盲区；导弹燃尽滑翔段告警中断是真实行为） |
| 音频占位 | AC6 解包告警音或合成，接 4 个槽位 |
