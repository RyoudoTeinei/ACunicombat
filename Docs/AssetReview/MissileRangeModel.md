# 导弹参考航程与实时可达性

## 基础参数

弹体干质量、主推进剂质量、RCS推进剂质量、各段推力和耗量、第二段最短点火间隔、离架初速、飞行寿命。飞行寿命作为独立的服务／自毁时限保留。

真空无阻力时，燃料耗尽后弹体仍然滑行。因此有限航程必须说明时间或交战条件，不能把燃料耗尽时刻当成飞行终点。

## 静态参考工况

静止发射平台，离架即点火，无横向机动，RCS燃料保留为质量。主发动机全推力；第二段采用允许的最早再点火与全推力。完成动力段后滑行到飞行寿命结束。自适应双脉冲的这个数值表示允许尽早点火的参考工况，不代表无目标时自动消耗第二脉冲。可变流量发动机的低推力巡航也会得到不同的航程。

## 解析算法

每段起始质量 m₀、燃料耗量 q、推力 F、起始速度 v₀、燃烧时长 t。时长受剩余燃料与剩余寿命限制。

- 末质量 m₁ = m₀ − q × t
- 有效排气速度 c = F / q
- 末速度 v₁ = v₀ + c × ln(m₀ / m₁)
- 本段位移 s = v₀ × t + c × [t − (m₁ / q) × ln(m₀ / m₁)]
- 间隔与末段滑行位移 s = v × t

按第一段、间隔、第二段、末段滑行顺序累加。计算使用double。参考航程按100米向下取整，火控内部保留连续精度。

## 数据流

MissileFlightProfile.Kinematics是共享动力输入。MissileKinematicProfile.RelativeTravelDistance负责分段解析计算，供参考航程与实时火控共同使用。MechWeaponPerformance按动力参数变化缓存参考航程，兼容旧序列化字段并覆盖其旧数值。effectiveRangeMeters不再向导弹提供静态有效射程。

配装页与资产页显示计算后的参考航程。实时火控使用相对位置、相对速度、航迹误差、可用飞行寿命和动力曲线求解交会时刻。弹体保留实际推进、RCS与目标可达性判断，不再因为累计飞满旧公里数而销毁。

## 验证

MechComputedMissileRangeTests用独立的2毫秒变质量数值积分核对14种弹药，误差要求小于100米。另测旧射程字段不影响结果、增加燃料与质量的正确趋势，以及双脉冲点火间隔的影响。真实弹体30/60Hz测试保留95%的到达要求，并按无目标时保留第二脉冲／最低节流的实际工况建立参照。
